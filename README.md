# Online-Judge

A Vue 3 single-page app for an online judge / programming-contest platform,
built with [Vite](https://vite.dev/), Vuex 4 and vue-router 4.

## Project setup
```
npm install
```

### Compiles and hot-reloads for development
```
npm run dev
```
Starts the Vite dev server on http://localhost:8080.

### Compiles and minifies for production
```
npm run build
```
Outputs the static bundle to `dist/`.

### Locally preview the production build
```
npm run preview
```

### Customize configuration
See the [Vite Configuration Reference](https://vite.dev/config/) and
[`vite.config.js`](./vite.config.js).
